My favourite: 许强个人作品集

定位：展示真实作品、制作过程及学习经历，帮助读者判断我能做什么。

最终四页：Home（介绍与精选作品）、Work（作品列表及说明）、About（背景与技能）、Contact（联系方式）。

优先做好 Work：每件作品说明问题、我的贡献、实现方法和改进空间。最小版本是四个互相连通的页面、一件真实作品和一个筛选交互，无登录或数据库。

当前四页是课堂练习结构；后续再将 Quotes 和 Project ideas 演进为作品及联系页面。

How I will build it

  1. 画出四页草图，整理真实作品与个人介绍。
  2. 写语义化 HTML，复用导航和页脚。
  3. 用一个 CSS 文件设计布局并检查手机宽度。
  4. 加入作品筛选，制作封面和图标。
  5. 持续提交 Git，之后上线并准备答辩。
